📋 Next Logical Steps
🛠️ Step 1: Backend Middlewares & Utilities
JWT Generator (server/utils/generateToken.js) – Token signing helper.
Auth Middleware (server/middleware/authMiddleware.js) – Protects endpoints by verifying JWTs.
RBAC Middleware (server/middleware/rbacMiddleware.js) – Enforces role permissions (GUEST, CUSTOMER, MANAGER).
Error Middleware (server/middleware/errorMiddleware.js) – Centralized error handler.
⚙️ Step 2: Controllers & API Routes
Auth (/api/auth): Register student, Login, Profile /me.
Users (/api/users): Manager student directory, profile notes, status toggles.
Bookings (/api/bookings): Interactive session scheduling, student bookings, manager session approvals, Zoom link additions, and invoice statuses.
Resources (/api/resources): Note & mnemonic uploader, role-based download filters (PUBLIC, CUSTOMER, PREMIUM).
Inquiries (/api/inquiries): Public contact form submissions & manager lead management.
🎨 Step 3: Frontend SPA (React + Vite)
Shared Layout: Navbar (with role-aware nav links), Footer, ProtectedRoute.
Public Views: Landing Page, RN Bio & Credentials, Courses, Contact Inquiry.
Student Portal: Student Dashboard, Booking Engine, Study Materials & Mnemonics.
Manager Admin Portal: Admin Dashboard, Schedule & Slot Manager, Student Directory, Resource Uploader, Inquiry Lead Manager.
